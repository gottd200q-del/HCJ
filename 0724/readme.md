HTML과 CSS, JavaScript를 이용해서 자기소개 페이지를 만들어줘.

초보자가 만든 포트폴리오 페이지처럼 너무 복잡하지 않게 만들어줘.

페이지 구성은 다음과 같이 해줘.

1. 상단 메뉴
- MY PAGE
- HOME
- ABOUT ME
- HOBBY
- FAVORITE
- DREAM
- 메뉴를 클릭하면 해당 section으로 이동하게 해줘.

2. 한국어 / 일본어 전환 기능
- KO / JA 버튼을 만들어줘.
- KO를 누르면 한국어로 표시
- JA를 누르면 일본어로 표시
- 페이지를 새로고침하지 않고 JavaScript로 바로 언어가 변경되게 해줘.

3. HOME
- "WELCOME TO MY PAGE"
- "안녕하세요!"
- "저를 소개합니다."
- 이름은 곽민선
- 성격과 취미, 좋아하는 것을 소개하는 페이지라는 내용
- 프로필 사진을 넣을 수 있게 해줘.
- 이미지 경로는 images/IMG_9519.jpeg로 해줘.

4. ABOUT ME
다음 정보를 넣어줘.

NAME
곽민선

AGE
24살

SCHOOL
경성대학교

MAJOR
동물보건생명과학과 전공

PERSONALITY
밝고 긍정적인 성격

MBTI
ISTP

그리고 MY STORY를 만들어서
새로운 것을 배우고 직접 경험하는 것을 좋아한다는 내용과
현재 HTML과 CSS를 공부하고 있다는 내용을 넣어줘.

5. HOBBY
취미를 4개 넣어줘.

- 음악 듣기
- 영화 보기
- 게임하기
- 사진 찍기

각각 간단한 설명도 넣어줘.

6. FAVORITE
좋아하는 것을 다음과 같이 넣어줘.

- 좋아하는 색: 보라색
- 좋아하는 계절: 봄
- 좋아하는 음식: 피자
- 좋아하는 장소: 바다
- 좋아하는 동물: 강아지
- 좋아하는 시간: 밤

7. DREAM
앞으로 이루고 싶은 목표를 넣어줘.

"내가 좋아하는 일을 하면서 행복하게 살아가는 것"

새로운 것을 배우고 다양한 경험을 하면서
꾸준히 성장하는 사람이 되고 싶다는 내용으로 작성해줘.

8. FOOTER
"THANK YOU FOR VISITING MY PAGE"
"© 2026 My Introduction Page"

9. 디자인
- 깔끔하고 귀여운 느낌
- 보라색 계열을 사용
- 너무 화려하지 않게
- 자기소개 포트폴리오처럼 보이게
- 카드 형태의 영역을 활용해줘.
- PC와 모바일에서 보기 편하게 만들어줘.

10. 코드
HTML, CSS, JavaScript를 각각 전체 코드로 만들어줘.
초보자가 이해하기 쉽게 주석도 넣어줘.
수정된 부분만 보내지 말고 복사해서 바로 사용할 수 있는 전체 코드를 보내줘.
